# SpaceDaze Game Design

This folder contains the product-facing rules, setting, progression, and
content plans for SpaceDaze.

- [Lore](lore.md) defines the setting, central conflict, characters, tone, and
  canonical terminology.
- [Floor themes](floor_themes.md) defines the cultures, factions, visual
  identities, hazards, and encounter styles used across generated floors.
- [Debris economy](debris-economy-plan.md) defines salvage values, pickup
  behavior, progression, and economy rules.
- [Enemy roster](enemy-roster-phase-2.md) defines combat roles, enemy families,
  encounter combinations, and roster expansion.

Engineering documentation, asset production records, and testing guides live
in the parent `docs` folder or beside the systems they describe.
