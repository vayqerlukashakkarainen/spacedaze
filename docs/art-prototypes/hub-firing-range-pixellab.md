# Hub firing range control

The firing range control unit was generated with PixelLab's Object tool and then normalized with the project's sprite normalizer.

- Runtime asset: `public/sprites/hub/firing-range-control.png`
- Sprite key: `hub_firing_range_control`

## Prompt

> SpaceDaze firing range equipment display pedestal, high top-down north-aligned view, battered improvised scavenger station rack with a broad angular base, four short mechanical clamps framing one central display socket, broken panels, exposed cables and patchwork plating, stark 1-bit pure white and pale gray silhouette with deep black cutouts, transparent background, hard pixel edges, no antialiasing, no gradients, no text, no floor, no shadow, native 64 by 64 pixel sprite

PixelLab produced the object at 128 × 128. The game uses it once as the firing range control unit at 92 × 92. Discovered abilities use a compact world-pickup presentation with one small rarity ring and an in-world **F** prompt. Equipping leaves every range pickup in place and shows a short loadout toast. The pickup rows refresh whenever the player discovers another system.
